# breadcrumbs

## Deps
- [Rust](https://rust-lang.org/tools/install/)
- [wasm-pack](https://drager.github.io/wasm-pack/)
    basically `cargo install wasm-pack`
- [Deno](https://docs.deno.com/runtime/getting_started/installation/)

## How to install
```cmd
cd ./frontend/svelte
deno install
```

## How to run
```cmd
deno task bind-wasm
deno task dev-sv
```
